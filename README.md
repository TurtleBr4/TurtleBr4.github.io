# Zaid Goodman Portfolio

Minimal static portfolio built with HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure
- `style.css` — visual styling
- `app.js` — project list rendering
- `projects.json` — editable project information

## Deploy
Copy these files into the root of `TurtleBr4/TurtleBr4.github.io` and push to GitHub Pages.

Add project screenshots to the repository and set their paths in `projects.json`. Add working game or source links when available. No build step or dependencies are required.
